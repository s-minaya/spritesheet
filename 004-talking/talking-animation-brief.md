# Talking animation brief — Ask Sofi

## Purpose
This animation is for **Sofi speaking to the user**.
The goal is to make her feel alive while text is being revealed (and/or while her voice/speech effect is active), keeping the result expressive, readable, and easy to integrate.

## Core intent
Sofi should:
- start from her **neutral, recognizable pose**,
- feel like she is **talking directly to the user**,
- keep a **front-facing gaze / direct eye contact** while speaking,
- animate in a way that feels **natural, lively, and loopable**, not like a rigid open-close mouth cycle.

This is not meant to be a big dramatic animation.
It should read as **dialogue / speaking / reacting live**, with subtle personality.

## Existing material
You can **reuse anything useful from the existing `sofi blink` spritesheet**.
That includes, for example:
- proportions,
- palette,
- line style,
- neutral pose,
- eye style,
- timing ideas,
- spacing/alignment conventions,
- any frame structure that helps keep consistency.

You do **not** need to rebuild things from scratch if reuse gives a better result.

## Creative freedom
You have **full freedom** to produce the best possible result.
There are **no formal acceptance criteria** for this repo task.

You may decide:
- final frame timing,
- loop structure,
- whether to slightly refine transitions,
- whether to mix talking with subtle idle life,
- how to best combine this with blink behavior,
- any implementation details needed for a clean final spritesheet.

## What matters most
Prioritize:
1. **Consistency with Sofi’s established look**.
2. **Clear “she is speaking” readability**.
3. **Smooth looping**.
4. **Pixel-art cleanliness**.
5. **Easy integration** in the separate repository.

## Desired feel
The animation should feel:
- cute,
- expressive,
- direct,
- polished,
- and unmistakably **Sofi**.
